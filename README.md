# DisfluencyLab
Speech → Feature Extraction → Log-Mel → ASR → CTC → Text → TTS → Speech, evaluated on stuttered speech (UCLASS).

## Workflow
1. Run `DisfluencyLab_Experiments_v2.ipynb` in Colab (GPU recommended). Section 10 downloads `disfluencylab_results.zip`.
2. Unzip into the project root: `results/` (CSVs, CTC posteriors, TTS audio) and `disfluency_utils.py`.
3. `pip install -r requirements.txt` then `streamlit run app.py`.

## Layout
```
data/audio, data/transcripts   # local only, never commit (minors' speech, UCLASS licence)
results/                       # generated by the notebook
disfluency_utils.py            # shared by notebook and app
app.py
```
## Method
Each model is scored against a **verbatim** reference (stutters kept) and a **clean** reference (intended text); see notebook Section 7.
Three recordings = pipeline pilot, not statistical evidence. Cite UCLASS and follow its terms.
